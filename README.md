## 💻 Sobre este Portfolio

Este sitio web fue construido desde cero con un enfoque en el rendimiento, la accesibilidad y el diseño minimalista.

- ⚡ **100% Responsive:** Adaptado fluidamente desde móviles (360px) hasta monitores 4K usando `clamp()` y CSS Grid/Flexbox.
- ♿ **Accesible:** Etiquetas ARIA, estados `:focus-visible` claros y respeto por `prefers-reduced-motion`.
- 🎨 **Diseño Moderno:** Tema oscuro con acentos en borgoña, utilizando las tipografías *Fraunces*, *Inter* y *JetBrains Mono*.
- 🚀 **Alto Rendimiento:** Sin frameworks pesados. HTML semántico, CSS optimizado y Vanilla JavaScript.
